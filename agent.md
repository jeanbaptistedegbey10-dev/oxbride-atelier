# OXBride Atelier — Rôle de l'agent

## Rôle de l'agent
Expert Next.js / Shopify Headless GraphQL.

## Conventions de code
- Functional Components uniquement.
- Hooks React optimisés.
- Animations fluides avec Framer Motion.
- Gestion propre des types TypeScript pour la Storefront API Shopify et les Metaobjects `atelier_experience`.
- Composants dans `src/components/`, typages dans `src/types/`, services GraphQL dans `src/lib/shopify/`.
- Stylage exclusivement via Tailwind CSS (aucun framework CSS externe).
